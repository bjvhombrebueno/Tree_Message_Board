# Tree_Message_Board
Tree_Message_Board COMP639 Assessment

This web app is of a Tree message board named Trees a Crowd. Similar to other message boards there are functions like user registration, creating and deleting posts and replies, profile management, and moderation. To get it to work, the Create database and Populate database SQL files should be run first to generate the required tables. The Python code can be run through the Visual Studio Code when run locally.If running on Pythonanywhere,the code should be pulled from Github and stored on its own directory.The requirements.txt should also be checked to see which modules are needed for the app to work. The create database script need to be edited to ensure that the correct database is being used, otherwise access will be denied.Then the scripts for database creation and population should be run. The config files for the web app should be setup as well to point to the correct directory, particlarly the WSGI file where you need to edit the 'from app import app as application'. The first 'app' needs to be changed to 'tree_message_board' for it to work. All of the profile images should be stored inside the static/images folder. For the profile image upload, the user has to input the filename through a text box.
